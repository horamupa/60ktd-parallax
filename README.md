# 60KTD — Siege / Parallax

Мрачная заставка Tower Defence: тяжёлые оборонительные башни слева, биомеханический рой справа, свободный центр для меню.

**Сайт:** https://horamupa.github.io/60ktd-parallax/

## Исходники

- assets/00-background.png — неподвижный фон, RGB.
- assets/01-defense-left.png — башни, RGBA.
- assets/02-swarm-right.png — жуки, RGBA.
- source/master-art.png — цельное полотно.
- source/game-sprites/ — три игровых спрайта, использованных как референсы.
- source/prompts.md — полные промпты генерации.
- downloads/60KTD-brutal-parallax-v2.zip — комплект PNG, исходная демонстрация и инструкция.

PNG экспортированы в 2560 × 1440 (16:9); нативные изображения image_gen 1672 × 941 увеличены macOS sips. Альфа-канал обоих боевых слоёв проверен.

## Сайт

Обычные HTML, CSS и JavaScript без внешних библиотек. VIEW ART скрывает меню, OPTIONS меняет силу движения, SOURCE открывает репозиторий. Меню остаётся неподвижным. Параллакс работает от курсора, касания и медленного автоматического движения; учитывает prefers-reduced-motion.

Все слои имеют одинаковый полный холст; не обрезайте прозрачные поля при импорте в игру. Увеличение на 4% даёт запас для движения. Оба передних слоя сдвигаются с разной скоростью.

Локальный запуск: `python3 -m http.server 8000` из корня репозитория, затем открыть http://localhost:8000.

GitHub Pages публикуется из корня ветки main. Файл .nojekyll отключает обработку Jekyll. В репозитории нет сборки или внешних зависимостей.
